## Публикация

1. Распакуй ZIP-архив. Все файлы уже настроены — никакой Python или `git` устанавливать не требуется.
2. Открой [создание репозитория](https://github.com/new) в аккаунте `sergeinikulin3838-AQA`.
3. В **Repository name** введи `sergeinikulin3838-aqa.github.io`. Выбери **Public**, галочку создания README не ставь (наш README уже есть).
4. Нажми **Create repository**.
5. На экране пустого репозитория нажми **uploading an existing file** (или **Add file → Upload files**).
6. В распакованной папке выдели **все файлы**, перетащи на страницу загрузки (или нажми **choose your files**). Не загружай сам ZIP и не помещай всё во вложенную папку. В корне репозитория обязательно должен быть `index.html`.
7. Напиши сообщение коммита `Add QA portfolio website`, нажми **Commit changes**.
8. Открой в репозитории **Settings → Pages**. В **Build and deployment → Source** выбери **Deploy from a branch**; в **Branch** выбери `main` и `/(root)`, нажми **Save**.
9. Открой https://sergeinikulin3838-aqa.github.io/ . Публикация может занять до 10 минут.

## Если страница выдаёт 404

- Убедись, что репозиторий называется `sergeinikulin3838-aqa.github.io` и принадлежат аккаунту `sergeinikulin3838-AQA`.
- Проверь, что `index.html` лежит в корне, а не в папке.
- Проверь **Settings → Pages** и успешность сборки в **Actions**.
- Дай публикации немного времени после сохранения настроек.

Появление в поиске и ответах ChatGPT не гарантировано.
